# Larkin Palm Springs PM&R Hub

The residents' website: https://larkinpscpmr.github.io

- `index.html` is the whole website. It reads and saves data through the Hub's
  Google Apps Script web app, which uses the **Hub Data** Google Sheet in the
  program Drive. Chiefs update content in that sheet, not here.
- The icons and `manifest.webmanifest` make "Add to Home Screen" show the palm-tree app icon.
